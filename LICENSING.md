The administration and operator tooling — formerly described here as a proprietary "closed layer,
sold separately" — has been **open-sourced under AGPL-3.0** as GLESAC
(https://github.com/Elyon-Sol/GLESAC). There is no longer a closed layer.

## History

Elyon-Sol was built as an open-core project: an AGPL core meant to be inspected, adopted, and
attacked, with a proprietary admin SDK and commercial core licenses intended to fund the work.
That funding did not materialize; the project is retired, and everything has been released under
AGPL-3.0. Should anyone carry it forward, contributions are welcome under `CONTRIBUTING.md`.
